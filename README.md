# ANDI Pro Market

Web application for a metal fabrication company.
Frontend: **React**
Backend: **Node.js (Express)**
Database: **MySQL**

---

## 1. Requirements

Before starting, make sure you have the following installed:

- Node.js **18+**
- npm
- MySQL (conveniently via **XAMPP**)
- Git (optional)

---

## 2. Installing dependencies

### Frontend

In the project root:

```bash
npm install

Backend

cd server
npm install
```

## After

```bash
cd ./metal-site
npm start
```

```bash
cd ./metal-site
cd ./server
node server.js
```
